# 提炼来源与规范化决定

提炼日期：2026-11-17。来源是用户提供的旧项目fip-causal-reasoning；本规范不修改原项目，也不在运行时读取它。

| 项目 | 来源观察 | 本规范决定 |
|---|---|---|
| 视觉基线 | app.py用户校准色：#B37560/#FEFAF7/#FDFCFA/#FCFBF9；旧design-system-spec.md使用#8C6B5D/#FDFBF7 | 采用当前主页暖色基线，不把不同历史副本当成同时有效的默认 |
| 小字白色主按钮 | #B37560对白字约3.73:1；原hover#9E5F4E约5.00:1 | 保留前者为品牌accent，后者作为可读主操作色；明确偏离原主按钮的原因 |
| 设置/资料配色 | 原设置面板保留旧主色，与主页不一致 | 新库默认统一语义角色；不保留旧组件私有色作为隐含主题 |
| 标题字重 | 表格写700，文字又说不超过600；首页28/700 | display/h1明确允许700，其他标题600 |
| 极小字号 | 原页面包含8–11px | 新组件最低12px；不是逐像素复制所有历史细节 |
| 字体 | 多个系统字体栈；声明JetBrains Mono但没有字体文件或加载 | 合并系统回退栈；mono声明可回退，不随包打字体也不访问CDN |
| 4px与控件内部值 | 旧规范说所有间距4倍数，但有10/14pxpadding | 区分布局栅格与有名的组件内部例外 |
| 阴影 | 卡片、输入有轻暖灰阴影；资料条目弱化卡片感 | 定义普通/flat两种表面，不套第一套的静态阴影禁令 |
| 布局 | 当前主页侧栏240/72、详情380/250，文档曾写280 | 采用当前实现值；1100/920断点；三栏作为可选模式 |
| 弹窗 | 原普通440、密码400、反馈560、展开1100 | 采用400/440/560/1100组合档，去除密码、账号等业务绑定 |
| 图谱 | 分类/关系极性/置信度有多组颜色 | 独立命名分类与关系token；不把颜色解释为真实医疗或因果结论 |
| 接入方式 | Gradio承载HTML/CSS/JS，子页iframe隔离，后端与日志集成 | 提取框架无关token/CSS/示例；不携带Gradio补丁、iframe服务、日志、密钥或后端 |
| 动画资产 | 图片、个人品牌、APNG和视频 | 不复制；静态状态应完整可读，动效可选 |
| 完整图谱引擎 | 原型含2D/3D外部依赖与数据 | 仅提供关系视图组合示意，不声称提供G6/Three.js/医疗数据 |

新规范起始版本1.0.0。新增加的小按钮32px、语义类名、token命名空间与无依赖构建/本地示例属于可复用化实现决定，不宣称逐项来自原项目。
