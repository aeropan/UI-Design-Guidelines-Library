IMPLEMENTATION / AI HANDOFF

从规范到实际前端

给 Codex / WorkBuddy

先读取本套 ai/AGENTS.md，再读取 DESIGN.md 和 packages/theme/src/tokens.json。按需参考本页组件与组合示例。

本套为浅色主题，不混入标准设计系统的靛蓝、AntD 尺寸、双主题或禁用静态阴影等规则。

给前端项目

保留原有技术栈。安装本地主题包，或复制构建产物的两份 CSS；用目标框架接好事件与业务数据。

import '@warm-apricot-cream/theme/tokens.css';
import '@warm-apricot-cream/theme/components.css';

// token-only JavaScript，不依赖 React / Gradio / AntD
import { tokens, colors, typography } from '@warm-apricot-cream/theme';

尚未在 npm 发布；按 README 先构建并生成 .tgz，再安装实际文件路径。

字体、状态和交互需要一起复用。外观一致不代表业务能力已接通；不能把“界面示例”包装成真实推理或医疗结论。
